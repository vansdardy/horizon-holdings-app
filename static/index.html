Backend not running

本页的净值曲线与持仓记录需要本地后端提供数据与持久化存储。启动方式:

cd app
pip install -r requirements.txt
python server.py            # → http://127.0.0.1:8000

然后用 http://127.0.0.1:8000 打开本页(而不是直接双击 HTML 文件), 前两节的组合结构分析在离线状态下依然可用。

首次启动后点一次「立即抓取一次」即可播种指数,此后后端每天 FETCH_HOUR(默认18点) 自动抓取一次。数据存在 app/portfolio.db(SQLite 单文件),备份直接复制该文件即可。
