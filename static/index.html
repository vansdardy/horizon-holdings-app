PORTFOLIO CONSTRUCTION · 20–30 YEAR HORIZON

巴菲特式全球价值组合

以巴菲特/Berkshire核心选股逻辑为基准 —— 可理解的商业模式、可持续的经济护城河、 诚信且资本配置能力强的管理层、合理的估值安全边际 —— 构建的78支个股组合, 覆盖11个Bloomberg板块与12个市场(美/加/日 + 英/法/德/荷/瑞士/比利时/意大利/丹麦/爱尔兰)。 科技板块对chokepoint型公司(如ASML、Arm、东京电子)做了适度放宽,但排除纯题材投机标的； 欧洲覆盖已按需求扩展,卢森堡经评估后未纳入(详见持仓表说明)。

模型指数净值 Model Index NAV

规则:初始NAV = 100亿(基准货币,默认CHF)÷ 2亿份 = 每份 50.00;后端每日收盘后抓取一次价格并重算NAV; 只买整数股,余额按上市地本币留存(7个货币现金池);每年首个交易日按信心分目标权重再平衡一次。 这是一条从部署当天开始向前累积的真实净值曲线 —— 不是回测。

净值序列以 ? 播种,但当前配置(.env 里的 BASE_CCY)是 ?。两种货币混在一条曲线里没有意义,继续抓取会被拒绝。 重置会清空净值历史并以新货币从今天重新播种 —— 你的持仓、现金、价格存档都不受影响。

后端未运行

本页的净值曲线与持仓记录需要本地后端提供数据与持久化存储。启动方式:

cd app
pip install -r requirements.txt
python server.py            # → http://127.0.0.1:8000

然后用 http://127.0.0.1:8000 打开本页(而不是直接双击 HTML 文件), 前两节的组合结构分析在离线状态下依然可用。

首次启动后点一次「立即抓取一次」即可播种指数,此后后端每天 FETCH_HOUR(默认18点) 自动抓取一次。数据存在 app/portfolio.db(SQLite 单文件),备份直接复制该文件即可。

06

我的持仓 My Positions

填入你实际持有的股数与平均成本(每股,以该股上市地本币计) —— 就是券商账户里显示的那两个数字。 系统会算出浮盈浮亏、你的实际权重、与目标权重的偏离度,以及补齐到目标权重还差多少股。 定投过程中每次加仓后更新一下,就能看到自己的组合怎样一步步向目标结构靠拢。
⚠ 关于「还差多少股」这一列

该列是纯数学计算:按你当前组合总市值 × 目标权重,再减去你已持有的市值,换算成股数。 它不考虑你的现金、税务处理(TFSA/RRSP/非注册账户的差异)、交易成本、汇率成本、也不判断当前价格是否合适。 它是一个对照工具,不是买入建议。实际操作请自行判断,必要时咨询持牌顾问。
